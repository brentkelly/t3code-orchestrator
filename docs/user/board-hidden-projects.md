# Hide a project from the board

The board shows every project's cards by default. To take a project off the board without
touching its work, open **Settings** → **Board** and, under **Card keys and colour**, select the
eye on the project's row. The row shows a **Hidden** badge while the project is hidden; select
the eye again to bring it back.

A hidden project disappears from the board view entirely: its cards leave the columns, and the
project leaves the scope picker, the colour legend, and the new-card project list. Nothing else
changes — the cards keep their stages and order, running work carries on, and the project's
threads stay in the Threads view. Showing the project again restores everything exactly as it
was.
