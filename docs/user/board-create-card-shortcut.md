# Creating a card from the keyboard

**Ctrl+Enter** creates the card you are writing in the **New card** dialog, the same as selecting
**Create card**. On a Mac it is **⌘Enter**, and the Create button shows whichever of the two your
machine uses.

It works from anywhere in the dialog — the title, the brief, the dependency search — so you never
have to get back to a particular field to finish. Enter on its own still does what it always did:
a new line in the brief, a selection in a picker.

The shortcut does nothing while the card is not ready to be created: no title, or a file still
uploading. The Create button is greyed out at those moments for the same reason.

See also [Drafts on the New card dialog](./board-card-drafts.md).
