# Moving between the board and your threads

T3 Code opens on the board. Launching the app, or opening it at its address, puts the cards in
front of you, because the board is where work is planned, watched and picked up.

## Switching modes

**Board** and **Threads** sit side by side as a pair of tabs. Selecting one takes you back to where
you were the last time you were in that mode — the thread you were reading, or the board scoped to
the project you were watching — rather than dumping you at that mode's front page.

Going home stays going home. Deleting a thread, discarding a draft or closing settings returns you
to your threads, exactly as before. Only opening the app fresh takes you to the board. Finishing a
pairing does too, so a newly connected device starts where everyone else does.

## Where the tabs sit

In board mode the tabs are in the top bar, next to the T3 Code wordmark.

In threads mode they move up into the sidebar's header, beside the same wordmark, whenever that
header is wide enough to hold them. Drag the sidebar narrower and the tabs move back down into the
top bar; drag it wider and they return to the header. Collapsing the sidebar has the same effect as
making it narrow: the tabs go to the top bar, so the board is never more than one selection away.

Both positions are the same control, and neither of them is a setting to configure — the tabs go
wherever there is room for them.

## The board's corner menu

The board has no sidebar, so **Settings**, **Pull Requests** and **Usage** live in a small floating
menu in its bottom-left corner. It is the same menu the sidebar carries in threads mode, so the
destinations and their icons match.

Select the **‹** at its right-hand end to collapse the menu down to a single chevron, and the **›**
that replaces it to bring the menu back. A collapsed menu stays collapsed the next time you open the
app. The board keeps the corner's space reserved either way, so no card is ever hidden underneath
the menu.

Collapsing the menu also hides the app-update indicator that shares it. If an update finishes
downloading while the menu is collapsed, T3 Code still tells you.
