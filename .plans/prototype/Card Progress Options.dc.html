Which thread the card shows

Priority: a thread awaiting input, then a running thread, then the most recently updated. Ties go to the thread you last opened, so the card keeps showing the list you were reading.

Where the full picture lives

The card modal already has thread tabs. Each tab gets its own todo list at the top of the transcript, so nothing on the card has to explain more than one thread.

When the list is stale

A stopped or idle thread's list drops to muted text with no spinner. A finished list collapses to the meta row as a single check and count, so completed cards stay quiet.
