USAGE

Token usage and cost per card

Every agent thread (planning, build, CI fix, each review / triage / adjudicate round, conflict fix) rolls its usage up to its stage, its card and its group. Cost is written in plain ink: no hue, so it never reads as a status. Green stays done, blue running, violet waiting on you, amber blocked. The number carries its own honesty marks instead.

1 Card face: cost appears only once the card is Done

Until a card reaches Done its face is exactly as today: no figure, not even on hover. In Done the settled total takes the right end of the existing meta row, so no card grows a line. While work is in flight, cost lives in the card's Summary pane, the List view and the board header.

Emphasis is weight, not colour

A Done figure is muted-fg at 500. At or over the board threshold ($5, set in Automation) it turns full ink at 600. Nothing else changes, so the status hues stay the only colour on a card.

Final, so no live marks

A Done card has no running steps, so "so far" never reaches the board. Only ≈ and + can appear, and the tooltip says which steps caused them.

Moved back out of Done

If a Done card is reopened, the figure leaves its face with it and the total keeps accruing in the detail pane. It returns when the card is Done again.

The server pushes one usage delta per finished turn. The card, stage and group totals re-render once on that event. No counters, spinners or interpolation. "so far" and the static blue step dot are the only in-progress cues, and both drop when the step settles.

3 Group cards: rolled-up total once Done, per-child on click

A group follows the card rule: no figure on its face until the group itself is Done. While it is in flight, the total sits in its lane header when you drill in (3b). It counts every child, including nested groups, and carries + or ≈ if any child does. Click the figure for per-child totals. Inside the group's board, the same total sits in the lane header next to progress.

4 Board level: a header total, and a Cost column in List

The total follows the filter: it sums the cards currently in view, so typing in "Filter tasks" changes it. The popover breaks it down by column and provider. That's all there is. No charts, no date range. Spend over time belongs on the Usage page behind the sidebar's usage icon.
