PRIORITY

Card priority: four levels, each one a scheduling rule

Today cards take worker slots in the order they were queued, with a one-off override. This adds a single priority field to every card, with four named levels and Normal as the default. The highest priority waiting card always gets the next free slot; within a level it stays first come, first served. It is a field, not labels, so a card can only have one priority and the queue can sort on it directly. It is named levels, not a 1–10 scale, because nobody can tell a 6 from a 7 and everything drifts upward. Each level is defined by what the scheduler does with it, and the picker says so.

1The four levels
!Urgent High Normal default Low Takes the next free slot, ahead of everything else. Doesn’t stop work that is already running. Goes ahead of every Normal and Low card. First come, first served, as the board works today. Only starts when no Normal or higher card is waiting. If the queue never empties, it never runs. For nice-to-haves.

Stored as a small integer (Low 0, Normal 1, High 2, Urgent 3). The queue hands out cards ordered by priority, highest first, then by the time each card was queued, oldest first. The existing one-off override stays and moves a card to the front of its own level.

5Decisions to make before building
Should Urgent interrupt running work? Should waiting cards move up over time? Should Urgent be limited? Recommended: no. “Next free slot” is usually fast enough, and stopping an agent halfway is messy. A later option could keep one slot free for Urgent cards. Recommended: not yet. Under heavy load, High cards can hold Normal cards back indefinitely. Low should never move up, since waiting is its point. Add a time-based bump for Normal only if cards actually get stuck. Recommended: no cap. Make Urgent cards stand out on the board so overuse is visible to everyone, and revisit if it gets abused.

Why here

Priority isn’t used much, so it sits quietly near the bottom, above Dependencies, with no emphasis. It is easy to skip, but still in view before Create card. It is a full-width row rather than a dropdown beside Label so the four options and the rule for the chosen one are visible without opening anything.

The rule text swaps as you pick: Low reads “Only runs when a worker would otherwise sit idle.” Urgent reads “Enters Building ahead of every waiting card.”

Keyboard: with focus anywhere in the dialog, Alt+1–4 sets priority without leaving the title or brief.

Creating from a column’s + uses the same dialog, so the default stays Normal there too.
